* File Staging: Allocate a temporary unlinked inode via `openat(..., O_TMPFILE | O_RDWR | O_CLOEXEC, 0640)`

`renameat2(AT_FDCWD, tmp_path, AT_FDCWD, target_path, RENAME_NOREPLACE)` or `mv -T`.
* Path Traversal Shielding: Resolve target directories using `openat2` with
`RESOLVE_BENEATH | RESOLVE_NO_SYMLINKS` flags to completely eliminate directory
traversal and symlink race attacks.

```rust

        .create()?
        .add_rule(PathBeneath::new("/run/server_script"), AccessFs::from_read_write(ABI::V4))?
        .add_rule(PathBeneath::new("/var/lib/server_script"), AccessFs::from_read_write(ABI::V4))?
        .add_rule(PathBeneath::new("/etc"), AccessFs::from_read(ABI::V4))?
        .add_rule(PathBeneath::new("/usr"), AccessFs::from_read(ABI::V4))?

}

```
