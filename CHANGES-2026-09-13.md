# Changelog - Core & Web Hardening

- **Refactored error handling** in `src/interface/web.rs` for `add_user_handler`, `update_user_handler`, `delete_user_handler`, `user_install_app_handler`, `user_uninstall_app_handler`, and `user_passwd_handler`.
- Errors occurring during spawned blocking tasks in user management handlers are now explicitly logged instead of silently discarded.
- Re-aligned `deny.toml` configuration by managing duplicate transitive dependencies (`crypto-common`, `getrandom`, `rand`).
- Maintained adherence to the core requirement of maintaining zero `clippy` warnings and strict `cargo deny` / `cargo audit` results.
